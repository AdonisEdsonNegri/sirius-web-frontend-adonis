🏠 Introdução ao SIRIUS WEB

ℹ️

Bem-vindo ao SIRIUS WEB!

SIRIUS WEB é um sistema ERP completo de gestão empresarial multi-tenant (SaaS), desenvolvido para atender múltiplas empresas com diferentes necessidades e versões personalizadas.

📌 O que é Multi-Tenant (SaaS)?

Multi-tenant significa que uma única instalação do sistema atende múltiplas empresas (tenants), cada uma com seus próprios dados e configurações completamente isoladas.

Exemplo prático:

  • Empresa A: Usa versão completa (PDV + Estoque + Financeiro)
  • Empresa B: Usa versão intermediária (PDV + Estoque)
  • Empresa C: Usa versão básica (apenas PDV)

Todas usando o mesmo sistema, mas com funcionalidades diferentes!

🎯 Modelo de Negócio

O SIRIUS WEB opera em modelo SaaS (Software as a Service), onde:

  • ✅ Soft Clever é o proprietário e administrador do sistema
  • ✅ Empresas clientes contratam o uso do sistema
  • ✅ Cada empresa paga conforme o plano contratado
  • ✅ Soft Clever controla quais funcionalidades cada empresa tem acesso

👥 Hierarquia de Permissões

O sistema possui 3 níveis hierárquicos de usuários, cada um com permissões específicas:

SUPER ADMIN

👑 Super Administrador

Quem é: Você (Soft Clever) e sua equipe técnica

✅ Pode fazer:

  • Ver e gerenciar TODAS as empresas do sistema
  • Configurar parâmetros de qualquer empresa
  • Criar e editar definições globais de parâmetros
  • Controlar versões e funcionalidades por empresa
  • Acessar relatórios globais do sistema
  • Tudo que um Admin normal pode fazer

🔒 Identificação:

Campo is_super_admin = true na tabela usuarios

ADMIN

👨‍💼 Administrador da Empresa

Quem é: Dono ou gerente da empresa cliente

✅ Pode fazer:

  • Gerenciar apenas SUA empresa
  • Cadastrar vendedores, formas de pagamento
  • Configurar regimes tributários
  • Gerenciar produtos, clientes
  • Usar PDV, emitir NFCe
  • Ver relatórios da empresa

❌ NÃO pode fazer:

  • Configurar parâmetros (isso é controlado por você!)
  • Ver ou acessar outras empresas
  • Alterar plano ou versão do sistema

🔒 Identificação:

Campo is_admin = true na tabela usuario_empresa para empresa específica

USUÁRIO

👤 Usuário Normal

Quem é: Funcionário da empresa cliente (vendedor, operador)

✅ Pode fazer:

  • Usar PDV (vender produtos)
  • Consultar produtos e clientes
  • Ver relatórios básicos

❌ NÃO pode fazer:

  • Cadastrar vendedores ou formas de pagamento
  • Acessar configurações
  • Ver dados de outras empresas
  • Alterar parâmetros

🔒 Identificação:

Campo is_admin = false na tabela usuario_empresa

⚠️

Importante sobre Segurança:

O status de Super Admin deve ser concedido apenas à equipe da Soft Clever. Nunca torne um cliente Super Admin, pois ele teria acesso a dados de todas as empresas!

⚙️ Sistema de Parâmetros

🎯 O que são Parâmetros?

Parâmetros são configurações que controlam o comportamento do sistema para cada empresa. Eles permitem que você personalize funcionalidades sem alterar o código.

Exemplo prático:

Parâmetro: "Permite vendas com saldo negativo?"

  • Empresa A (valor: S): Pode vender mesmo sem estoque (saldo fica negativo)
  • Empresa B (valor: N): Sistema bloqueia venda se não tiver estoque

Mesmo parâmetro, comportamentos diferentes!

🏗️ Arquitetura (2 Tabelas)

📋 parametros_definicoes

Definições Globais (mesma para todas empresas)

  • Código: PEDIDO_PERGUNTA_QUANTIDADE
  • Descrição: Pergunta quantidade ao adicionar produto?
  • Tipo: BOOLEAN (S/N)
  • Valor Padrão: N
  • Módulo: PDV

✨ Você cria essas definições como Super Admin

⬇️

💾 parametros_valores

Valores por Empresa (cada empresa tem o seu)

  • Empresa 1: PEDIDO_PERGUNTA_QUANTIDADE = S
  • Empresa 2: PEDIDO_PERGUNTA_QUANTIDADE = N
  • Empresa 3: (não configurou, usa padrão = N)

✨ Você configura esses valores por empresa

📊 Tipos de Parâmetros

Tipo Descrição Exemplo
BOOLEAN Sim ou Não S, N
INTEGER Número inteiro 1, 10, 100
DECIMAL Número decimal 1.5, 10.99
SELECT Lista de opções Opção1, Opção2, Opção3

🎯 Parâmetros Atuais do Sistema

1️⃣ PEDIDO_PERGUNTA_QUANTIDADE

Descrição: Ao escolher um produto para um item de pedido perguntar qual será a quantidade

Tipo: BOOLEAN (S/N)

Valor Padrão: N

Comportamento:

  • S (Sim): Sistema abre modal perguntando quantidade (padrão 1)
  • N (Não): Adiciona produto automaticamente com quantidade 1

2️⃣ PERMITE_SALDO_NEGATIVO

Descrição: Permite vendas com saldo negativo?

Tipo: BOOLEAN (S/N)

Valor Padrão: N

Comportamento:

  • S (Sim): Permite vender mesmo sem estoque (saldo fica negativo)
  • N (Não): Bloqueia venda se estoque insuficiente

🎯 Como Configurar Parâmetros

✅

Apenas Super Admin!

Somente usuários com permissão de Super Admin podem acessar e configurar parâmetros. Clientes não têm acesso a essa funcionalidade.

📍 Passo a Passo

1

Acessar a Tela de Configuração

No menu principal, clique em: Configurações → ⚙️ Parâmetros

💡 Ou acesse diretamente: parametros-config.html

2

Selecionar a Empresa

No topo da tela, use o dropdown para selecionar qual empresa deseja configurar:

  • Você verá TODAS as empresas cadastradas
  • Escolha a empresa que deseja configurar
  • Os parâmetros dessa empresa serão carregados automaticamente
3

Visualizar Informações da Empresa

Após selecionar, você verá:

  • Razão Social
  • CNPJ
  • Plano contratado (FREE, BASIC, PRO, etc)
4

Alterar Valores dos Parâmetros

Para cada parâmetro você verá:

  • Código: Identificador técnico
  • Descrição: O que o parâmetro faz
  • Dropdown de valores: S/N ou outras opções
  • Badge: "PADRÃO" ou "CUSTOMIZADO"

Clique no dropdown e escolha o novo valor. O campo ficará amarelo indicando modificação.

5

Salvar Alterações

Após alterar os valores desejados, clique em:

💾 Salvar Todas Alterações

Uma mensagem de confirmação aparecerá e os valores serão salvos!

6

Resetar para Padrão (Opcional)

Para voltar um parâmetro ao valor padrão:

  • Clique no botão 🔄 ao lado do parâmetro customizado
  • Ou use 🔄 Resetar Todos para Padrão para resetar todos de uma vez
💡

Dica Profissional:

Você pode alternar entre empresas sem sair da tela! Basta selecionar outra empresa no dropdown e configurar seus parâmetros. Muito eficiente para configurar várias empresas rapidamente!

Cenário 1: Empresa com Controle Rígido de Estoque

Necessidade: Nunca vender produtos sem estoque

Configuração:

  • PERMITE_SALDO_NEGATIVO = N

Cliente: Loja de Roupas XYZ

Necessidade: Vender produtos que ainda não chegaram (encomendas)

Cliente: Restaurante Bom Sabor

Necessidade: Perguntar quantidade de cada item (ex: 2 refrigerantes, 3 cervejas)

Configuração:

  • PEDIDO_PERGUNTA_QUANTIDADE = S

Cliente: Conveniência 24h

Necessidade: Vendas rápidas, sempre 1 unidade por vez

Configuração:

  • PEDIDO_PERGUNTA_QUANTIDADE = N

Resultado: Clica no produto, já adiciona quantidade 1 (mais rápido)

❓ Perguntas Frequentes (FAQ)

❓ Clientes podem ver ou alterar parâmetros?

Não! Apenas Super Admins (você e sua equipe) podem ver e configurar parâmetros. Clientes nem veem o menu de configuração.

❓ O que acontece se eu não configurar um parâmetro para uma empresa?

O sistema usa automaticamente o valor padrão definido na criação do parâmetro. Por exemplo, se PERMITE_SALDO_NEGATIVO tem padrão "N", empresas não configuradas usarão "N".

❓ Posso criar novos parâmetros?

Sim! Como Super Admin, você pode acessar "Parâmetros → Definições" e criar novos parâmetros globais. Depois, configura os valores por empresa.

❓ Como faço para resetar todas configurações de uma empresa?

Na tela de configuração, selecione a empresa e clique em "🔄 Resetar Todos para Padrão". Todos parâmetros customizados voltarão aos valores padrão.

❓ Posso configurar parâmetros diferentes para filiais da mesma empresa?

Atualmente cada "empresa" no sistema é independente. Se você cadastrar Matriz e Filial como empresas separadas, pode configurar parâmetros diferentes para cada uma.

❓ Alterações em parâmetros entram em vigor imediatamente?

Sim! Assim que você salva, os usuários da empresa já usarão os novos valores na próxima ação que executarem.

❓ Consigo ver histórico de alterações em parâmetros?

O sistema registra updated_at (data/hora) e updated_by (quem alterou) na tabela parametros_valores. Para ver, consulte diretamente no banco de dados.

❓ Como torno alguém da minha equipe Super Admin?

Execute no banco de dados PostgreSQL:

UPDATE usuarios 
SET is_super_admin = true 
WHERE email = 'email@domembro.com';

⚠️ Cuidado: Super Admin tem acesso a TUDO!

❓ Parâmetros afetam performance do sistema?

Não! Os parâmetros são consultados quando necessário e são muito leves. O impacto em performance é desprezível.

❓ Posso ter parâmetros por módulo (PDV, NFCe, etc)?

Sim! Ao criar um parâmetro, você define em qual módulo ele se aplica. Na tela de configuração, os parâmetros são agrupados por módulo automaticamente.

📖 Glossário de Termos

Super Admin
Usuário com permissões globais que pode acessar e configurar todas as empresas do sistema. Geralmente a equipe da Soft Clever.
Admin
Administrador de uma empresa específica. Pode gerenciar sua empresa mas não outras empresas ou parâmetros globais.
Multi-Tenant
Arquitetura onde um único sistema atende múltiplas empresas (tenants) com dados isolados.
SaaS (Software as a Service)
Modelo de negócio onde o software é oferecido como serviço, geralmente por assinatura mensal.
Parâmetro
Configuração que controla comportamento do sistema sem alterar código.
Definição de Parâmetro
Estrutura global que define o que é um parâmetro (código, descrição, tipo, valor padrão). Mesma para todas empresas.
Valor de Parâmetro
Valor específico configurado para uma empresa. Pode ser diferente do padrão.
Valor Padrão
Valor que será usado se a empresa não tiver configuração customizada para aquele parâmetro.
Customizado
Quando uma empresa tem valor específico configurado, diferente do padrão.
Tenant
Uma empresa/cliente no sistema multi-tenant. Cada tenant tem seus dados isolados.
ERP
Enterprise Resource Planning - Sistema de gestão empresarial integrado.
PDV
Ponto de Venda - Módulo para realizar vendas diretas ao consumidor.
NFCe
Nota Fiscal de Consumidor Eletrônica - Documento fiscal obrigatório para vendas.
